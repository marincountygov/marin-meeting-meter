Meeting Cost Calculator: Simple Estimate Mode Specification1. Overview & RoutingThe Meeting Cost Calculator will adopt a dual-mode architecture. The new default interface will be a streamlined "Simple Estimate Mode" that calculates costs based on total attendee count and a distribution slider. The existing line-by-line participant calculator will be preserved as the "Detailed Mode".   Routing Logic: On application load, evaluate the URL query parameters. If the parameter ?calc=legit is present, render the Detailed Mode. If it is absent or has any other value, render the Simple Estimate Mode.   Implementation: Wrap the existing detailed participant card in a container (e.g., <div id="meeting-detailed-participants">) and create a parallel container for the simple mode (e.g., <div id="meeting-simple-participants">). Toggle their hidden attributes based on the query parameter during initialization.   2. Calculation Logic & Data ProcessingThe Simple Estimate Mode relies on dynamic rate calculation derived directly from the Open Data JSON payload.   Dynamic AnchorsUpon successful fetch and parsing of the w7uw-fvda.json dataset:Map the dataset to extract a single hourly base rate for each classification.   Use the application's established rule: select Step 5 if available and positive; otherwise, select the highest published positive hourly step.   Filter out any classifications that do not have a valid positive hourly rate.   Sort the resulting array of hourly rates in ascending order.   Determine the Left Anchor (0%) by taking the 15th percentile of this sorted array.Determine the Right Anchor (100%) by taking the 85th percentile of this sorted array.Linear InterpolationThe per-attendee base hourly rate is calculated using linear interpolation based on the slider's 0-100 value:Base Rate = Left Anchor + ((Slider Value / 100) × (Right Anchor - Left Anchor))Meeting TotalsSalary Cost: Base Rate × Total Staff Attendees × Duration in Hours.   Estimated Employer Costs: Salary Cost × Employer Cost Percentage (which defaults to 138% and remains editable in the Meeting Setup block).   Estimated Total Meeting Cost: Salary Cost + Estimated Employer Costs.   3. Copy UpdatesAppend the following specific text to the end of the existing content inside the <section id="about"> element:   Simple Estimate ModeBy default, the calculator provides a rapid estimate based on the total number of attendees and a staff distribution slider. The slider interpolates between two dynamically calculated rates derived from the currently published County job classes: the 15th percentile of hourly pay rates (representing Administrative and Support staff) and the 85th percentile (representing Executive and Director staff). Moving the slider establishes a blended average hourly rate per attendee based on that selected distribution. This blended base rate is then multiplied by the standard 138% estimated employer cost.To build an estimate using specific, line-by-line participant classifications and pay steps, access the detailed calculator by adding ?calc=legit to the web address.
